## 1. 화면 — `test/browser/check_dateedge.mjs`

시계를 그 시각으로 옮겨(브라우저 `page.clock` · 검사 쪽 Node 는 `fake_now.mjs`) 주요 화면을 엽니다.

| 시각 (한국) | 왜 |
|---|---|
| 2026-11-30 23:58 | 달 끝 자정 직전 |
| 2026-12-01 08:30 | 월초 아침 — UTC 로는 아직 11월 30일 |
| 2026-12-31 23:55 | 연말 |
| 2027-01-01 08:30 | 새해 아침 — UTC 로는 지난해 |
| 2028-02-29 08:30 | 윤일 아침 |
| 2027-03-31 10:00 | 31일 — 「한 달 전」 계산이 넘치는 날 |

보는 것: 화면 오류 · 오류 칸 없음(내부 14화면 · 현장 2 · 병원 6), 위쪽 시계 · 오늘 일정 제목 · 폰 날짜 띠 · 달력 달이
**한국 날짜**로 그날, 월 마감 · 병원 리포트가 이번 달(또는 마감할 지난달).

**결과 — 6시각 모두 통과(192).** 앱의 「오늘」은 한국 시각으로 고정(`today()`)되어 있고, 달 이동은 1일 기준 · 산수로
계산해 2월 31일 같은 넘침이 없습니다. 코드에서 UTC 날짜를 쓰는 15곳도 확인했습니다 — 모두 날짜 글자끼리의 계산이거나
(UTC 기준 그대로 더하고 뺌) 90 · 180일 같은 넉넉한 기간의 경계라 하루 차이가 결과를 바꾸지 않습니다.

## 2. 검사 — 날짜를 옮긴 전체 회귀

`FAKE_NOW` 를 주면 `_pw.mjs` 가 새로 여는 브라우저 창마다 시계를 옮기고, `node --import ./fake_now.mjs` 로 검사 쪽
시계도 옮깁니다. 평소(`FAKE_NOW` 없음)에는 아무것도 바뀌지 않습니다.

```bash
cd test/browser
FAKE_NOW=2026-11-27T10:00:00+09:00 node --import ./fake_now.mjs check_month.mjs
```

2026-11-27(금) 10:00 — 「5일 뒤」가 12월로 넘어가는 달 끝 주 평일 — 로 전체 회귀를 돌린 결과는 아래 3장에 적습니다.
