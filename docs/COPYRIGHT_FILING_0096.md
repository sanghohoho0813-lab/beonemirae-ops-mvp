## 3. 주요 기능 (명세서용 요약)

1. 수거 1회 입력 → 일정·이력·거래처·자재·통계·문서 초안 자동 반영
2. 병원 고객 포털 — 수거 요청·긴급 요청·용기 주문·월간 리포트·정산 열람
3. 요청 → 배차 → 수거 → 정산의 폐쇄 업무 흐름
4. 실적 이관 — 거래처별 상이한 정산 엑셀 양식 자동 해석(11개 실양식)
5. 통장 입금 대사 · 월말 청구 일괄 확정 · 미수 관리
6. 도입 전/후 성과 자동 측정 (표본 미달 시 산출 보류하는 검증 로직 포함)
7. 역할별 권한(대표·관리자·사무·현장·병원) 및 행 단위 접근 제어

## 4. 복제물 제출 준비

등록에는 소스코드 복제물(통상 앞뒤 일부)이 필요합니다.
저장소에서 다음으로 뽑을 수 있습니다:

```bash
# 소스 전체 목록과 앞 30줄 (제출 형식은 신청 시 안내에 맞출 것)
git archive HEAD src supabase/migrations -o /tmp/bwm-src.zip
```

## 5. 집계 재현 명령

```bash
find src -name '*.ts' -o -name '*.tsx' | wc -l                  # 파일 수
find src -name '*.ts' -o -name '*.tsx' | xargs wc -l | tail -1  # 줄 수
ls supabase/migrations/*.sql | wc -l                            # 마이그레이션 수
git log --reverse --format=%ad --date=short | head -1           # 개발 시작일
```
