# 0139 · 심사 시연 발표 가이드 (Presenter Mode)

> 신용보증기금 스타트업지점 심사 시연용. **안내만 하는 층**입니다 — 업무 로직 · 데이터 ·
> 권한 · 성과 계산을 바꾸지 않습니다. 대표님이 누르는 것은 실제 화면의 실제 버튼이고,
> 저장되는 것은 실제 기록입니다.

## 쓰는 법 (대표님)

1. 관리자 계정 → 메뉴 「심사 시연」(`/presentation`, 화면 제목 「발표 가이드」)
2. **시연 준비 상태** 확인 — 화면이 확인할 수 있는 것만 자동 ✓, 나머지(인터넷 · 프로젝터 ·
   새로고침)는 직접 체크. **시연 거래처**를 고릅니다(실제 거래처면 주의 표시 — 요청 · 수거
   기록이 그 병원 기록으로 남습니다).
3. **「심사 시연 시작」** → 안내 카드가 화면을 옮겨도 따라다닙니다.
4. 카드의 **▶ 지금 할 일**대로 누르고, 「다음 단계」를 누르면 그 단계 화면으로 데려갑니다.
5. 마지막 「발표 가이드 종료」 → 카드 · 강조 · 진행 기록이 모두 사라지고 평소 화면입니다.
   중간에 끝내려면 카드의 ✕ → 「끝내기」 (한 번 더 묻습니다 — 잘못 눌러도 시연이 날아가지 않게).

## 7단계 (5~7분)

| 단계 | 화면 | 강조(보이는 첫 대상 하나) | 상태 |
|---|---|---|---|
| 시작 | `/presentation` | 흐름 띠 (병원 → 요청 → 직원 확인 → AI 업무보조 → 현장 처리 → 운영 데이터 축적) | — |
| 1 오늘 운영 화면 | `/` | 오늘 할 일 · 오늘 수거 칸 | 구현됨 |
| 2 현장 수거 1회 입력 | `/collection` | 저장 결과 → 「수거 완료 저장」 | 구현됨 |
| 3 병원 포털 요청 | `/portal/c/<시연 거래처>` (관리자 미리보기) | 완료 화면 → 「긴급수거 요청하기」 → 「긴급수거 요청」 | 실증 단계 |
| 4 직원 요청함 + AI 업무보조 | `/requests` | 「초안 사용」 → 「AI 분석 실행」 → 「회신 남기기」 | 구현됨 |
| 5 직원 회신 → 병원 확인 | `/requests` → `/portal/c/<id>/requests` | 병원 「담당자 안내」 → 「회신 저장」 → 요청 줄 | 구현됨 |
| 6 발표용 성과 화면 | `/performance/ir` | 도입 전 업무부담 칸 | 측정 중 |
| 7 마무리 | `/presentation` | 마무리 판(구현됨 · 실증 단계 · 향후 계획 + 마지막 문장) | — |

카드 한 장 = ① 지금 보여드리는 것 ② 기존 ③ 바뀐 방식(구현된 것만) ④ 기대 효과(정성) ⑤ ▶ 지금
할 일 + 발표자 메모(기본 접힘, 두세 문장).

## 화면 배치

- **넓은 화면**: 직원 화면은 왼쪽 메뉴 자리 위(시연 중 이동은 카드로), 병원 화면은 강조한
  버튼을 **가리지 않는 쪽**. 창(회신 · 요청 시트)이 열리면 짧은 카드(단계 · 지금 할 일 ·
  이전/다음)로 줄어 왼쪽에 붙습니다. 「이전 · 다음」은 늘 카드 맨 아래에 보입니다.
- **폰 폭**: 위쪽 한 줄 막대(단계 · 지금 할 일 · 다음) — 펼치면 아래 시트.
- 휴대폰 틀(`?frame=1`) 안, 60초 투어 진행 중, 현장 직원 · 병원 계정에는 나타나지 않습니다.

## 정직하게 표시하는 것

- **AI**: `ai_calls` 에 성공 기록이 있어야 ✓ (최근 성공 시각(한국 시각) · 모델). 마무리 판의 「AI 요청 분석」
  옆에도 성공 기록이 없으면 「실제 호출 확인 전」이 붙습니다. 없으면 「AI 실제 호출
  확인 필요」 — 실패하면 화면에 실패로 나오고 가짜 결과는 만들지 않습니다.
- 효과 문구에 검증 안 된 % · 시간 없음. 「자동 배차 · 수거량 예측 · 완전 자동화 · 병원 전체
  사용 · 전화가 없어진다」 없음. 105톤 · 49곳처럼 출처 미확정 숫자 없음 (테스트가 막습니다).

## 진행 상태 저장

- `sessionStorage['beonemirae-ops:presenter']` = `{ index, clientId, at }` — 같은 탭에서만,
  새로고침 · 화면 이동에도 이어짐, **3시간 지나면 버림**, 탭을 닫으면 사라짐.
- 시연 거래처 선택은 `localStorage['beonemirae-ops:presenter-client']` (다음 연습 때 다시
  고르지 않게). 업무 데이터 · 새 상태 라이브러리 · 외부 투어 라이브러리 없음.
- 강조는 `data-presenter-spot` 속성 하나(테두리만). 대상이 없으면 아무것도 하지 않습니다.
  새로 붙인 표식은 `Requests.tsx` 「회신 남기기」의 `data-presenter="reply-open"` 하나뿐.
