# 0103 — UI/UX 100점 고도화 · 병원 포털 모션/호버 · 전수 점검

> 대표님: 「전체 UI UX 100점짜리로 만들고 싶어. 다시 스스로 목표 설정해서
> 고도화. 병원 포털도 모션그래픽 효과, 마우스호버 효과 좀 잘 업그레이드.
> 그 외에도 지금까지 만들어놓은 기능들 오류 없는지 체크, 보완할 점 보완.」

둡니다 — 자 없이 100 을 적으면 그 숫자가 거짓이 됩니다.

## 넣은 움직임 — 전부 「누를 수 있다」「지금 여기다」를 알리는 정도

| 어디 | 무엇 | 얼마나 | 줄이기 설정에서 |
|---|---|---|---|
| 포털 머리 사진 (PC) · 로그인 옆 사진 | 아주 천천히 다가옴 (Ken Burns) | 28초에 6% | **완전히 멈춤** |
| 포털 「지금 하실 수 있는 일」 8장 | 0.05초씩 차례로 떠오름 | 전부 뜨는 데 0.6초 | 바로 보임 |
| 포털 카드에 마우스 | 카드 1~2px 뜸 · 위 선 4→6px · 아이콘 1.05배 · 화살표 4px → | 200ms | 즉시 |
| 포털 위 탭 | 청록 강조선이 **누른 탭으로 미끄러져** 감 | spring | 즉시 |
| 내부 왼쪽 메뉴 | 청록 강조 막대가 **누른 메뉴로 미끄러져** 감 | spring | 즉시 |
| 소모품 상품 카드 | 카드 뜸 · 사진 4% 다가옴 | 300ms | 즉시 |
| 포털 목록 줄(요청·최근 활동) | 아주 옅은 띠 | 150ms | 즉시 |

지키는 선:
- **폰은 그대로 정적**입니다. 머리 사진이 폰에 없으니 드리프트도 없고, 카드
  hover 는 폰에서 pressed(눌린 느낌)로만 보입니다. 첫 화면에서 「수거 요청」
  자리는 1px 도 안 바뀝니다(`check_flow390`).
- 아이콘 1.1배 미만 · 화살표 8px 미만 · 140~250ms — 자가 못 박아 둡니다.
  「모션그래픽」이라고 화면이 춤추면 병원 담당자는 놀라고 기사님은 멀미합니다.
- 강조선(탭·메뉴)은 **장식 하나만** 움직이고 바탕색은 그 자리에 둡니다. 대비
  자(a11y_measure · check_theme)는 부모 배경만 보므로, 배경까지 움직이는
  요소로 만들면 글자 대비가 「없음」으로 읽힙니다.
- 사진 드리프트는 `animation: none` 으로 끕니다. 0.01ms 로 줄이기만 하면
  무한 반복이 **깜빡임**이 됩니다.

## Esc — 맨 위 창 하나만

병원 화면 창은 Esc 로 닫혔는데 내부 창(Modal)은 안 닫혔습니다(0094 P2).
창마다 제각기 keydown 을 듣게 두면 더보기 시트 위에 「계획 중」 미리보기가
떠 있을 때 Esc 한 번에 **둘 다** 닫힙니다. `useEscapeClose` 로 열린 창을
쌓아 두고 마지막 것만 닫습니다. Modal · BottomSheet · PortalSheet 셋이 같은
쌓기를 씁니다. 한글 조합 중 Esc 는 창을 닫지 않습니다(쓰던 글이 날아갑니다).

## 20장째 — 로그인 옆 세로 패널

`mobile_card_vertical.jpg`(9:16)는 가로 화면들에 자리가 없어 0097 부터 P2 였습니다.
**로그인 화면의 PC 옆**이 딱 세로입니다. 직원도 병원도 제일 먼저 보는 화면인데
검은 바탕에 칸 하나뿐이었습니다. 폰(lg 미만)에서는 안 그립니다 — 로그인 칸이
첫 화면 아래로 밀리면 안 됩니다. 로그인 칸 자체는 한 글자도 안 바뀌었습니다
(`check_login` 22/0 그대로).

| 분류 | **PRODUCT DEFECT (기존)** — 0103 과 무관합니다. 주말에는 방문이 없어 자가 못 잡다가 화요일 회귀에서 처음 잡혔습니다 |
| 처치 | 「자세히」를 10px 띄움 → `check_scale` **316 / 0** |
| 최종 확인 | check_scale 316/0 · check_motion 28/0 · check_hover 18/0 · check_login 22/0 · check_devreq 114/0 · tsc 0 |

붙을 단추 자체가 안 그려집니다. 주중에 한 번 더 도는 것이 안전합니다.
