# 검증 (test)

㈜비원미래 운영관리 파일럿의 회귀 검사입니다.

> ⚠ **왜 저장소에 넣었는가**
>
> 이 검사들은 원래 개발 작업공간에만 있었습니다. 작업공간은 일정 시간이 지나면
> 회수되므로, 그때 검사 136개가 **통째로 사라집니다.** 그러면 다음 사람은
> 「전체 회귀 실패 0」이 무슨 뜻인지 확인할 방법이 없고, 파일럿 중에 무엇이
> 깨졌는지 되짚을 수도 없습니다. 그래서 코드와 같은 자리에 둡니다.

## 무엇이 들어 있나

| 자리 | 내용 |
|---|---|
| `test/browser/check_*.mjs` | 화면 검사 135개 — 시늉본 서버 위에서 실제 브라우저로 돕니다 (`check_evidence0106` 은 브라우저 없이 계산층만) |
| `test/db/db_*.mjs` | DB 검사 40개 — 격리 PostgreSQL 에 마이그레이션을 처음부터 올리고 돕니다 |
| `test/browser/walk_all.mjs` | **눌러서 도는 전수 점검** (아래 참고) |
| `test/browser/a11y_*.mjs` | 글자 크기 · 색 대비 · 손가락 크기 재기 |
| `test/browser/ux_*.mjs` | 터치 수 · 스크롤 횟수 · 화면 이동 수 재기 |
| `test/browser/perf_fixtures.mjs` | 3년치 실측 규모 시늉 자료 (거래처 18 · 수거 5,600여 건) |

## 돌리는 법

```bash
#  ⚠ 먼저 .env.local 이 있어야 합니다. 없으면 앱이 「서버 연결이 설정되지
#    않았습니다」 화면에서 멈추고 **화면 검사가 전부 로그인 화면을 봅니다.**
#    검사는 서버를 흉내 내므로 **진짜 값이 아니어도 됩니다.**
#    (0094 에서 작업공간이 회수된 뒤 이것 때문에 한참 헤맸습니다.)
cat > .env.local <<'ENV'
VITE_SUPABASE_URL=https://test-not-real.supabase.co
VITE_SUPABASE_ANON_KEY=test-anon-key-not-a-real-secret
ENV

npm ci                                            # node_modules 가 없으면
npm run build && npx vite preview --port 4173 &   # 화면 검사는 만들어진 판을 봅니다
PW_MODULE=/경로/node_modules/playwright \
  bash test/browser/run.sh                        # 화면 검사
bash test/db/run.sh                               # DB 검사 (로컬 PostgreSQL 16 필요)
```

> `.env.local` 은 `.gitignore` 에 걸려 있어 저장소로 올라가지 않습니다.
> **실제 운영 키를 여기에 넣지 마세요.** 검사에는 필요 없습니다.

`「검사 0」은 통과가 아니라 실패입니다.` 검사가 도중에 터지면 한 건도 못 하고
끝나는데, 그것을 0/0 으로 세면 **깨진 검사가 조용히 통과한 것처럼 보입니다.**
실제로 그렇게 숨어 있던 검사가 있었습니다. 두 runner 는 그것을 따로 셉니다.

## 눌러서 도는 전수 점검 (`walk_all.mjs`)

```bash
ROLES=field,admin,office,client node test/browser/walk_all.mjs
```

보통 검사는 **주소를 직접 쳐서** 화면을 엽니다. 그런데 실제로 찾은 결함 하나는
주소로 열면 멀쩡하고 **눌러 들어가야만** 드러났습니다 (오늘 일정 → 병원 줄 →
수거 입력에서 저장 단추가 영영 꺼져 있던 것). 자료가 이미 들어와 있느냐로
화면 상태가 갈리기 때문입니다.

그래서 이 점검은 **맨 처음 한 번만** 주소를 치고, 그다음부터는 사람처럼 눌러서만
돌아다니며 찾습니다.

- 눌러도 아무 일이 없는 단추
- 눌렀더니 빈 화면 / 오류 글이 뜨는 곳
- 화면을 여는 순간 콘솔에 터지는 오류
- **다 채웠는데 저장이 꺼져 있는 곳** ← 위에서 말한 그 종류

거짓 경보를 줄이려고 다음은 결함으로 세지 않습니다: 지금 보고 있는 화면의
메뉴를 다시 누른 것, 새 탭·전화·메일로 나가는 바깥 링크, 이미 골라져 있는 것을
다시 누른 것.

## 실계정 검사

`check_live_*.mjs` 와 `a11y_field.mjs` 는 진짜 계정으로 돕니다. 계정 정보는
**환경변수로만** 넘깁니다 — 파일·코드·커밋에 비밀번호를 적지 않습니다.

```bash
E2E_EMAIL=… E2E_PW=… node test/browser/check_live_field.mjs
```

환경변수가 없으면 그 검사는 **건너뛰었다고 말하고** 넘어갑니다. 조용히
통과한 척하지 않습니다.
