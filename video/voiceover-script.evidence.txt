비원미래 AX Evidence Guide — 경영진용 내레이션 대본
전체 886자 · 차분히 읽으면 약 2분 20초 (영상 전체 약 2분 30초)

이 영상이 전하려는 한 줄
  AX Evidence 는 심사를 위해 따로 만드는 자료가 아니라,
  회사가 실제로 일하면서 남기는 변화의 기록입니다.

읽는 법
 · 아홉 장면을 끊지 말고 한 번에 이어서 읽어 주세요. 파일 하나면 됩니다.
 · 장면 사이에는 아래 [쉼] 만큼 쉬어 주세요. 그동안 화면이 다음 장면으로
   넘어갑니다. 이보다 짧으면 말이 화면을 앞지릅니다.
   (적힌 초는 짐작이 아니라 실제 촬영에서 화면이 걸린 시간을 잰 값입니다.)
 · 대표님과 이사님께 설명드리는 자리입니다. 광고 낭독이 아니라, 담당자가
   차분히 근거를 설명하는 속도로 읽어 주세요.
 · 다 읽으신 파일은 video/audio/voiceover.evidence.wav 로 넣어 주시면 됩니다.
   ⚠ 50초짜리 짧은 Demo 의 voiceover.wav 와는 **다른 파일**입니다.

══════════════════════════════════════════════════════════════════════

[INTRO · 왜 기록이 필요한가]   어두운 글자 화면

AX를 만들었다는 사실보다 중요한 것은, 회사가 실제로 어떻게 달라지고
있는가입니다. 그 변화가 데이터로 남아야 설명할 수 있습니다.

   [쉼 약 1초]   ← 글자 화면이 실제 AX 코치 화면으로 녹아듭니다

──────────────────────────────────────────────────────────────────────

[PART 1 · AX 코치가 지금 상태를 본다]   AX 코치 — 준비도 · 네 갈래

AX 코치는 프로그램을 몇 번 눌렀는지 세지 않습니다.
실제 업무 기록을 기준으로 어떤 데이터가 남았고 무엇이 부족한지 봅니다.
준비도는 점수가 아니라 쌓인 기록을 정리한 값입니다.

   [쉼 약 1.5초]

──────────────────────────────────────────────────────────────────────

[PART 2 · 부족한 것을 실제 업무로 연결]   AX 코치 — 오늘 이것만 해주세요

부족하다고 경고만 하지 않고, 그 데이터를 만들 수 있는 실제 업무로
이어 줍니다.
「했다」 단추는 없습니다. 눌렀다고 완료되지 않고, 실제 기록이 생겨야
확인됩니다.

   [쉼 약 2.5초]   ← 미션을 눌러 수거 입력 화면으로 이동합니다

──────────────────────────────────────────────────────────────────────

[PART 3 · 증거를 위해 따로 하는 일이 아니다]   수거 입력

현장에서 하는 일은 평소와 같습니다.
거래처를 고르면 폐기물 구분과 주소가 따라오고, 수거량과 두고 온 용기,
오늘 쓴 차량을 넣습니다.

   (여기서 한 호흡 — 화면에서 칸이 하나씩 채워집니다)

증거를 만들려고 보고서를 따로 쓰지 않습니다.
원래 하던 업무를 AX에서 하면 그 기록이 곧 근거입니다.

   [쉼 약 2초]   ← 저장을 누르고 결과 화면이 뜹니다

──────────────────────────────────────────────────────────────────────

[PART 4 · 하나의 기록이 회사 여러 업무로]   저장 결과

저장은 한 번입니다. 오늘 일정이 완료되고 수거이력이 생깁니다.
거래처 활동과 월간 수거량이 바뀌고, 두고 온 용기만큼 사무실 재고가 줄고,
인계 상태와 명세 초안까지 이어집니다.
한 번 입력한 기록이 여러 업무에 다시 쓰입니다.

   [쉼 약 2.5초]   ← 왼쪽 목차에서 AX 코치로 돌아갑니다

──────────────────────────────────────────────────────────────────────

[PART 5 · 실제로 했는지 다시 확인]   AX 코치 — 오늘 확인된 것

다시 AX 코치입니다.
완료했다고 말해서 인정하지 않고, 실제 수거 기록이 생긴 것을 확인하고
반영합니다.
증거는 따로 쓴 문서가 아니라 시스템에 남은 행동과 결과입니다.

   [쉼 약 2초]   ← AX 도입 성과 화면으로 넘어갑니다

──────────────────────────────────────────────────────────────────────

[PART 6 · 기록이 쌓이면 변화가 측정된다]   AX 도입 성과

기록이 쌓이면 변화가 숫자로 보입니다.
한 건 입력에 걸린 시간, 한 번 입력으로 자동 반영된 업무, 당일 입력 완료율.
아직 못 잰 것은 숫자를 만들지 않고 미측정으로 둡니다.

   [쉼 약 1초]   ← 성과 화면 위로 마무리 문구가 떠오릅니다

──────────────────────────────────────────────────────────────────────

[PART 7 · 이 데이터가 왜 회사 성장에 중요한가]   성과 화면 + 핵심 문구

이 데이터는 먼저 내부 경영에 쓰입니다.
어디에서 시간이 오래 걸리는지, 무엇을 먼저 고쳐야 하는지 판단할 수
있습니다.
충분히 쌓이면 회사의 변화와 실행력을 외부에 설명하는 근거로도 쓸 수
있습니다.

   [쉼 약 1초]   ← 닫는 글자 화면으로 넘어갑니다

──────────────────────────────────────────────────────────────────────

[OUTRO · 닫는 말]   어두운 글자 화면

AX를 쓰는 과정이 회사의 변화 기록이 됩니다.
그 데이터가 다음 성장의 근거가 됩니다.

   (화면 아래 「비원미래 AX · AX Coach」 가 남고 끝납니다)

══════════════════════════════════════════════════════════════════════

화면에는 나오지만 읽지 않는 문장이 둘 있습니다 — 글자 화면에 띄웁니다.

  여는 화면 아래
    「누가, 언제, 어떤 업무를 했고 그 결과 무엇이 달라졌는지가
     데이터로 남아야 AX 도입의 변화도 설명할 수 있습니다」
    「이 기록은 내부 운영 개선의 기준이 되고, 앞으로 회사의 성장과
     실행력을 외부에 설명하는 근거가 됩니다」

  PART 7 (성과 화면 위)
    「정책자금 · R&D · 투자 · 사업 확장」

  ⚠ 「이 데이터를 보여주면 자금이 나온다」 「기관이 Evidence 로 인정한다」
    같은 말은 대본에도 화면에도 넣지 않았습니다. 쓸 수 있는 표현은
    「회사의 변화와 실행력을 설명하는 근거로 활용할 수 있다」까지입니다.

녹음하신 뒤

  1. video/audio/voiceover.evidence.wav 로 넣습니다
  2. npm run video:evidence:say  — 파일 길이를 재고 장면 시각의 「출발점」을 찍어 줍니다
  3. 들어 보고 고쳐서 video/config.evidence.json 의 voiceover.marks 에 적습니다
  4. npm run video:evidence     — 음성 붙은 MP4

  ⚠ 다시 녹음하시면 marks 숫자만 고치면 됩니다.
  ⚠ 50초짜리 짧은 Demo 는 그대로 있습니다 — npm run video 로 따로 만듭니다.
