비원미래 AX — 경영진용 소개영상 내레이션 대본
전체 795자 · 차분히 읽으면 약 2분 8초 (영상 전체 약 2분 25초)

읽는 법
 · 여덟 장면을 끊지 말고 한 번에 이어서 읽어 주세요. 파일 하나면 됩니다.
 · 장면 사이에는 아래 [쉼] 만큼 쉬어 주세요. 그동안 화면이 다음 장면으로
   넘어갑니다. 이보다 짧으면 말이 화면을 앞지릅니다.
 · 경영진에게 설명하는 자리입니다. 광고 낭독이 아니라, 담당자가 차분히
   근거를 설명하는 속도로 읽어 주세요.
 · 다 읽으신 파일은 video/audio/voiceover.executive.wav 로 넣어 주시면 됩니다.
   (50초짜리 짧은 Demo 의 voiceover.wav 와는 다른 파일입니다.)

[INTRO · 여는 말]   어두운 글자 화면

AX를 도입하는 목적은 프로그램 하나를 만드는 것이 아닙니다.
실제 업무의 변화를 데이터로 남기고, 그것이 회사의 성장 증거가 되게
하는 것입니다.

   [쉼 약 1초]   ← 실제 AX 코치 화면으로 넘어갑니다

──────────────────────────────────────────────────────────────────────

[PART 1 · 지금 무엇이 비었나]   AX 코치 — 준비도 · 네 갈래

AX 코치는 기능을 몇 번 썼는지 세지 않습니다.
실제 업무 기록을 기준으로, 지금 어떤 증거가 쌓였고 무엇이 비었는지
봅니다.
업무 활용, 매출 증거, 운영 확장, 병원 직접사용 네 갈래로 나눠 봅니다.

   [쉼 약 1.5초]

──────────────────────────────────────────────────────────────────────

[PART 2 · 업무로 연결]   AX 코치 — 오늘 이것만 해주세요

비어 있는 것을 경고만 하지 않습니다.
그 증거를 만들 수 있는 실제 업무 화면으로 바로 이어 줍니다.
「했다」 단추는 없습니다. 눌렀다고 인정되지 않습니다.

   [쉼 약 2.5초]   ← 미션을 눌러 수거 입력 화면으로 이동합니다

──────────────────────────────────────────────────────────────────────

[PART 3 · 현장 입력]   수거 입력

현장에서는 원래 하던 입력을 그대로 합니다.
거래처를 고르고, 다녀온 날과 수거량을 넣고, 오늘 쓴 차량을 고릅니다.

   (여기서 한 호흡 — 화면에서 칸이 채워집니다)

증거를 만들려고 따로 보고서를 쓰지 않습니다.
해야 할 업무를 하면 그 기록이 그대로 증거가 됩니다.

   [쉼 약 2.5초]   ← 저장을 누르고 결과 화면이 뜹니다

──────────────────────────────────────────────────────────────────────

[PART 4 · 한 번 입력이 여러 업무로]   저장 결과

저장 한 번으로 오늘 일정이 완료되고 수거이력이 만들어집니다.
거래처의 최근 활동과 월간 수거량, 통계 수치가 함께 바뀝니다.
처리장 인계 상태와 월간 명세 초안까지 이어집니다.
한 번 입력한 기록이 여러 업무에서 다시 쓰입니다.

   [쉼 약 2초]   ← 왼쪽 목차에서 AX 코치로 돌아갑니다

──────────────────────────────────────────────────────────────────────

[PART 5 · 실제 기록인지 확인]   AX 코치 — 오늘 확인된 것

다시 AX 코치입니다. 방금 넣은 기록을 코치가 직접 찾아 확인합니다.
완료라고 눌러서가 아니라, 실제 기록이 생겼기 때문에 확인된 것입니다.

   [쉼 약 2초]   ← AX 도입 성과 화면으로 넘어갑니다

──────────────────────────────────────────────────────────────────────

[PART 6 · 회사의 데이터가 된다]   AX 도입 성과

쌓인 기록은 성과 화면에서 숫자가 됩니다.
입력에 걸린 시간, 한 번 입력이 자동으로 반영한 업무, 당일 입력 완료율.
아직 못 잰 것은 못 쟀다고 그대로 둡니다.
이 기록이 나중에 투자와 정책자금, 사업 확장을 설명하는 근거가 됩니다.

   [쉼 약 1초]   ← 닫는 글자 화면으로 넘어갑니다

──────────────────────────────────────────────────────────────────────

[OUTRO · 닫는 말]   어두운 글자 화면

업무를 바꾸고, 그 변화를 데이터로 남기고,
그 데이터가 회사의 다음 성장 근거가 됩니다.

   (화면 아래 「비원미래 AX · AX Coach」 가 남고 끝납니다)

⚠ 화면에는 나오지만 읽지 않는 문장이 하나 있습니다.
   여는 글자 화면 아래쪽에 작게 띄웁니다 —

     「쌓인 기록은 운영 개선뿐 아니라, 향후 투자·정책자금·R&D·사업 확장
      과정에서 회사를 설명하는 근거가 됩니다.」

   여는 말을 8~12초 안에 끝내려면 세 문장은 들어가지 않습니다. 대신 같은
   뜻을 PART 6 마지막 문장에서 말로 합니다. 글로 한 번, 말로 한 번입니다.

녹음하신 뒤

  1. video/audio/voiceover.executive.wav 로 넣습니다
  2. npm run video:exec:say   — 파일 길이를 재고, 장면 시각의 「출발점」을 찍어 줍니다
  3. 들어 보고 고쳐서 video/config.executive.json 의 voiceover.marks 에 적습니다
  4. npm run video:exec      — 음성 붙은 MP4

  ⚠ 다시 녹음하시면 marks 숫자만 고치면 됩니다.
  ⚠ 50초짜리 짧은 Demo 는 그대로 있습니다 — npm run video 로 따로 만듭니다.
