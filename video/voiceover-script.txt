비원미래 AX 심사 시연 영상 — 내레이션 대본
전체 283자 · 차분히 읽으면 약 45~48초

읽는 법
 · 여섯 장면을 끊지 말고 한 번에 이어서 읽어 주세요. 파일 하나면 됩니다.
 · 장면과 장면 사이에는 아래 [쉼] 만큼 쉬어 주세요. 그동안 화면이 다음
   장면으로 넘어갑니다. 이보다 짧으면 말이 화면을 앞지릅니다.
 · 광고 낭독이 아니라, 담당자가 차분히 설명하는 속도로 읽어 주세요.
 · 다 읽으신 파일은 video/audio/voiceover.wav 로 넣어 주시면 됩니다.

──────────────────────────────────────────────────────────────────────

[S1 · AX 코치]

비원미래 AX는 실제 업무 기록을 보고, 지금 부족한 증거와 오늘 해야 할 일을
먼저 보여줍니다.

   [쉼 약 1초]

[S2 · 실제 업무로 이동]

추천을 누르면 실제 업무 화면으로 바로 이동합니다.
완료 버튼만 누르는 방식이 아닙니다.

   [쉼 약 2초]   ← 화면이 수거 입력으로 넘어갑니다

[S3 · 수거 입력]

현장에서는 거래처와 차량, 수거량을 한 번만 입력합니다.
이 기록이 실제 사용 증거가 됩니다.

   [쉼 약 2.5초]   ← 저장을 누르고 결과 화면이 뜹니다

[S4 · 자동 반영]

저장 한 번으로 일정, 수거이력, 거래처, 재고와 인계 상태까지 함께
반영됩니다.

   [쉼 약 1초]

[S5 · 실제 기록 확인]

AX 코치는 방금 생긴 실제 기록을 다시 확인해 준비도를 갱신합니다.
임의로 만든 숫자가 아닙니다.

   [쉼 약 1초]

[Outro · AX 도입 성과]

이렇게 AX 도입의 변화를 실제 데이터로 남깁니다.

──────────────────────────────────────────────────────────────────────

녹음하신 뒤

  1. video/audio/voiceover.wav 로 넣습니다
  2. npm run video:say  — 파일 길이를 재고, 장면 시각의 「출발점」을 찍어 줍니다
  3. 들어 보고 고쳐서 video/config.beonemirae.json 의 voiceover.marks 에 적습니다
  4. npm run video      — 음성 붙은 MP4

  ⚠ 다시 녹음하시면 marks 숫자만 고치면 영상이 다시 만들어집니다.
