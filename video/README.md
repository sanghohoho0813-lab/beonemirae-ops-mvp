# 심사 시연 영상 (0111 · 무음 1차)

> 제품에 있는 **심사 시연 투어(demo · 다섯 단계)** 를 Playwright 가 사람 대신
> 눌러 가며 진행하고, 그 화면을 그대로 MP4 한 편으로 만듭니다.
>
> **투어를 복제하지 않습니다.** 단계 순서·문장·강조·덮개는 전부 제품의
> `TourOverlay` 가 그리는 그대로이고, 여기 있는 것은 「누르는 손」뿐입니다.
> 투어를 고치면 영상이 따라옵니다.

## 만드는 법

```bash
npm run build && npm run preview     # 다른 창에서 띄워 둡니다 (localhost:4173)
npm run video                        # 녹화 + MP4 변환
```

결과물은 `video/out/` 에 생깁니다 (git 에는 올리지 않습니다).

| 파일 | 무엇 |
|---|---|
| `beonemirae-ax-60s.mp4` | **대표님이 보실 것** — 1280×720 · 30fps · 무음 |
| `demo.webm` | 브라우저가 남긴 원본 |
| `timeline.json` | 장면별 시각 + **아무것도 저장하지 않았다는 기록** |

따로 돌리려면 `npm run video:rec` · `npm run video:mux`.

## 실제 서버는 건드리지 않습니다

검사들이 쓰는 흉내 서버(`test/browser/walk_lib.mjs`)를 그대로 씁니다.

- 저장 요청은 흉내 서버가 받아 **성공한 척**만 합니다. 실제 Supabase 로는
  한 건도 나가지 않습니다.
- 바깥으로 나가는 요청은 **그물로 막고 세어서** `timeline.json` 에 남깁니다
  (`escapedRequests`). 정상이면 0건입니다.
- ⑤단계가 확인하는 「오늘 수거 완료 기록」도 흉내 서버가 만든 것입니다.
  다만 **확인 판정은 제품 로직 그대로**입니다 — 결과를 지어내지 않습니다.

그래서 화면 오른쪽 아래에 **「예시 데이터 · 기능 시연용」** 이 항상 떠 있습니다.

## 촬영용 기록 (0112)

기록이 하나도 없으면 AX 코치가 네 영역 모두 0% 라, 「아직 아무도 안 쓴다」로
보입니다. 이 영상이 보여 줄 이야기는 그게 아닙니다.

> 이미 일부 기록이 있다 → 코치가 **비어 있는 곳**을 찾는다 → 오늘 할 일을 준다
> → 사람이 한다 → 코치가 그 기록을 확인한다

그래서 `video/fixture.mjs` 에 **일부러 적은 양**을 고정으로 둡니다 — 지난 완료
방문 12건, **그중 현장 입력은 1건뿐**, 병원이 포털로 올린 요청 3건, 오늘 예정
1건. 「배차·완료는 하는데 현장 입력이 아직 안 쌓였다」는 그림이고, 그래서 오늘
할 일이 「수거 입력」이 됩니다.

**매출은 한 건도 만들지 않았습니다.** 주문·청구·입금을 지어내면 금액이 생깁니다.
「매출 증거 0%」로 남는 것도 사실입니다. 날짜는 오늘에서 며칠 전으로만 세므로
같은 날 몇 번을 찍어도 같은 화면이 나옵니다.

## 영상에만 더한 것 — 셋뿐입니다

1. 「예시 데이터 · 기능 시연용」 구석 표시
2. 부드러운 커서 (누르는 자리를 눈으로 따라갈 수 있게)
3. 오른쪽 위 도구 줄 감추기 — 제품은 투어가 끝나면 되돌려 놓는데, 영상에서는
   마지막 4초에 갑자기 나타나 산만합니다. **녹화하는 창에서만** 가립니다.

셋 다 `record.mjs` 가 브라우저에 끼워 넣습니다. **`src/` 는 한 줄도 바뀌지
않습니다.** 자막은 일부러 넣지 않았습니다 — 투어 설명 상자가 이미 같은
문장을 크게 보여 줍니다. 아래쪽 자막 자리는 **AI 음성**을 붙일 때 씁니다.

## 왜 1600×900 으로 찍어 1280×720 으로 줄이나

720 높이로 찍었더니 ④단계(저장 결과)처럼 긴 화면에서 **설명 상자가 내용을
덮었습니다.** 투어 배치는 900 높이에서 맞춰져 있습니다. 16:9 를 유지한 채
900 으로 찍고 줄입니다. 덮였는지는 촬영 중에 재서 `timeline.json` 의
`cardCoversSpot` 에 남깁니다 — 전부 0 이어야 합니다.
